# Procedure: Flow Sensor (FS1, FS2) Anomaly

**Failure mode:** Unexpected flow readings not matching motor power/pressure.

**Typical signature:** FS sensor importance elevated together with a
pressure/pump anomaly — flow is rarely the root cause on its own, it is
usually a symptom.

**First checks:**
1. Check for line blockage or kinks between the flow sensor and the pump.
2. Verify sensor calibration against a known reference flow rate if available.
3. If flow reads consistently zero, check for sensor power/signal fault
   before assuming a mechanical blockage.
